# me

A private daily task list (Hebrew, RTL) installable as a phone app. All data stays on the device.

- Develop: `npm install && npm run dev`
- Deploy: `npm run deploy` — runs tests, builds, and publishes `dist/` to the `gh-pages` branch.
- Live: https://davidblau300.github.io/me/ — never rename the repo; saved tasks are tied to this address.
